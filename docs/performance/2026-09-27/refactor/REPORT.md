# Dart 数据处理重构：实现与复测

完成了数值环形缓存、FFT 常驻分析 isolate、显示通知合并；控制协议和硬件后端未改变。

- SampleBuffer 使用 Float64List 存储时间和值，写满后覆盖最旧位置；实时入库不再移动整段列表或创建 Offset。
- 保留每路 1,800 点、冻结绘图快照、CSV 后端原始记录和多窗口增量游标的原有语义。大快照裁剪后仍保留原始总计数。
- 数据处理立即执行；telemetry、全局 UI 和窗口同步通知按显示时钟合并。
- FftAnalysisWorker 复用输入数据，最多一个活动任务和一个最新待办任务；过时结果返回 null，面板关闭时释放 isolate。
- FFT 核心使用类型化数组，完整频谱以均匀频率轴＋幅值数组保存。输入和完整输出通过 TransferableTypedData 传递，未丢弃频率分辨率。
- 数值数据类型、FFT 与 worker 是独立 Dart 模块，可共用于 pyOCD、probe-rs 等数据源。

## Release AOT：同类输入的前后对比

环境：12th Gen Intel(R) Core(TM) i5-12450H，31.71 GiB 内存，Flutter 3.47.0 / Dart 3.13.0。
每侧采用两个进程的测量，中位数区间如下。采样链路每批 64 帧，每路缓冲区预先填满 1,800 点。

| 项目 | 重构前 ms | 重构后 ms | 中位数均值之比 |
| --- | ---: | ---: | ---: |
| 32 路拆帧、解码、入库 | 18.679–23.870 | 0.024–0.024 | 899.4× |
| 128 路拆帧、解码、入库 | 73.967–125.588 | 0.093–0.093 | 1073.8× |
| 8,192 点完整 FFT 分析 | 1.077–1.707 | 0.486–0.490 | 2.9× |
| 131,072 点完整 FFT 分析 | 94.219–115.444 | 10.280–10.776 | 10.0× |
| 1,048,576 点完整 FFT 分析 | 2004.772–2288.210 | 118.377–118.891 | 18.1× |

以上倍率只对应各项计算，不等于整体应用或调试探针的加速倍率。CPU 频率和其他系统负载没有锁定，因此绝对数值有运行波动。微基准的 P95 是每块平均耗时的 P95；原始数据保留全部重复和参数。

## 生产 FFT worker

每种数据首次上传一次，此后九次分析复用输入，返回全部频谱点。下表稳态计时含命令、计算及结果传输；首请求另记录为 firstRequestMs。

| 输入规模 | 稳态耗时 ms | 主 isolate 最大心跳间隔 ms | 每轮数据上传次数 |
| --- | ---: | ---: | ---: |
| 131,072 点 | 13.702–13.802 | 17.196–17.779 | 1 |
| 1,048,576 点 | 123.845–126.990 | 17.538–17.766 | 1 |

心跳周期为 16 ms；这项指标衡量主 isolate 响应，不是实际显示 FPS。

## 持续采样＋真实 Widget＋FFT

使用 Windows Release 引擎和生产曲线、监视表、分析面板，在隐藏原生窗口中运行。模拟 32 路 × 每路 10 kHz 二进制样本；每 500 ms 改变 FFT 选区，复用 131,072 点输入。每轮约 8 秒，预热约 2 秒。

| 轮次 | 每路接收帧数 | 实际输入 Hz | build P95 ms | raster P95 ms | FFT 选区变化次数 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1 | 79936 | 9986.4 | 6.968 | 4.400 | 15 |
| 2 | 80000 | 9995.1 | 7.012 | 4.314 | 15 |

所有已发送帧均被解码并计入每路总数，缓冲区始终保留最近 1,800 点；停止时最后一个未满批次及定时器间隔未计为已发送数据，实际速率因而略低于标称值。全过程含启动的最大瞬时调度积压为 602.000–941.000 帧，随后按时间追赶处理，未静默丢弃。

build/raster 是引擎阶段耗时。隐藏窗口不等同于物理显示呈现；本测试没有连接硬件、没有 OS 进程管道、没有 CSV 录制，也没有同时开启多窗口。它验证了短时并发负载与数据完整性，不是长时间硬件压力认证。
